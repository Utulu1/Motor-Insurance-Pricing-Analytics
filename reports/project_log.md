# Project Log

## Purpose

This project log documents the major stages completed during the development of the Motor Insurance Pricing Analytics project. It provides a concise record of the analytical workflow, key decisions, and deliverables produced throughout the project.

---

# Project Timeline

## Phase 1 – Project Planning

### Activities Completed

- Defined the business problem.
- Established project objectives.
- Identified the analytical scope.
- Selected the French Motor Third-Party Liability (freMTPL2) dataset.
- Designed the project folder structure.

### Deliverables

- Project Brief
- Repository Structure
- Initial Documentation

---

## Phase 2 – Data Acquisition and Audit

### Activities Completed

- Imported the frequency dataset.
- Reviewed data structure and variable types.
- Assessed missing values.
- Checked duplicate records.
- Evaluated exposure values.
- Performed initial data quality assessment.

### Deliverables

- Data Audit Report
- Data Dictionary

---

## Phase 3 – Exploratory Data Analysis (EDA)

### Activities Completed

- Explored claim frequency distribution.
- Analysed driver age characteristics.
- Investigated vehicle age patterns.
- Examined exposure distribution.
- Assessed regional and geographic variables.
- Identified potential pricing risk factors.

### Deliverables

- Exploratory Visualisations
- Initial Business Insights

---

## Phase 4 – Feature Engineering

### Activities Completed

- Created driver age categories.
- Created vehicle age groups.
- Created population density bands.
- Encoded categorical variables.
- Prepared modelling dataset.
- Generated GLM-ready design matrix.

### Deliverables

- Enhanced Modelling Dataset

---

## Phase 5 – Statistical Modelling

### Activities Completed

- Developed baseline Poisson GLM.
- Developed enhanced Poisson GLM.
- Incorporated exposure offset.
- Estimated model coefficients.
- Interpreted statistical significance.
- Calculated Incident Rate Ratios (IRRs).

### Deliverables

- Baseline GLM
- Enhanced GLM
- Coefficient Interpretation

---

## Phase 6 – Model Validation

### Activities Completed

- Generated predicted claim frequencies.
- Calculated residuals.
- Evaluated prediction accuracy.
- Computed Mean Absolute Error (MAE).
- Computed Root Mean Squared Error (RMSE).
- Computed Mean Poisson Deviance.
- Compared observed and predicted claim frequencies.

### Deliverables

- Model Validation Results
- Residual Analysis
- Performance Metrics

---

## Phase 7 – Business Interpretation

### Activities Completed

- Identified significant pricing factors.
- Interpreted actuarial implications.
- Assessed business impact.
- Developed pricing recommendations.
- Documented model assumptions.
- Documented model limitations.

### Deliverables

- Business Insights
- Business Recommendations
- Final Conclusions

---

## Phase 8 – Repository Development

### Activities Completed

- Organised project files.
- Created project documentation.
- Produced visualisations.
- Designed professional README.
- Implemented consistent Anthony Utulu Analytics branding.
- Published the completed repository to GitHub.

### Deliverables

- GitHub Repository
- Documentation
- Visual Assets
- Portfolio Project
